# Noisemaker for Qt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement noisemaker-for-qt — DSL compiler, QOpenGL renderer, 210-effect library, and pixel parity harness — to family standard (0 FAIL ledger, six compiler gates + two byte gates green).

**Architecture:** Byte-identical reference GLSL corpus executed by a C++/QOpenGL render-graph backend behind the family's graph-JSON seam; renderer validated against reference-produced golden graphs first; C++ DSL compiler ported last behind byte-diff oracle gates. Spec: `/Users/alex/platform/noisemaker-for-qt/ARCHITECTURE.md`, `PORTING-GUIDE.md`, `docs/IMPLEMENTATION-PLAN.md`.

**Tech Stack:** Qt 6.11 (`/opt/homebrew/opt/qt`), C++17, CMake ≥3.21 + Ninja, Node ≥18 (tools/parity), Python 3 + numpy + Pillow (grading), Playwright headless Chromium (goldens, via the reference's vendored harness).

## Global Constraints

- Working repo: `/Users/alex/platform/noisemaker-for-qt` only. The reference `/Users/alex/platform/noisemaker` is READ/EXECUTE-ONLY (never modify, never build in, never `npm install` inside). Sibling ports are READ-ONLY.
- Never push, never add remotes, never open PRs. Local commits only, on `main`. No feature branches, no worktrees.

- Never blanket-kill `chrome-headless-shell`/browser processes — other sessions on this machine own some. Attribute by parent-chain/cwd first, kill only your own.
- Finish your task IN THIS RUN: block-wait in the foreground on sweeps/renders; never hand off to a detached wait-loop or report "will resume when notified."
- Long sweeps: run chunked, log progress to a file under `parity/out/`, and tail it in the foreground until the terminal `DONE` marker.
